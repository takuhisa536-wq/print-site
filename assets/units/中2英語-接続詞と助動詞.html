中2英語｜接続詞・助動詞 ドリル（1）

when・because・ifなどの接続詞と、must・shouldなどの助動詞を確認します。文法問題が中心です。

  1. 接続詞 because は、どのような意味を表しますか。
  2. 接続詞 when は、どのような意味を表しますか。
  3. 接続詞 if は、どのような意味を表しますか。
  4. 「あなたは宿題をしなければなりません。」を英語にしなさい。
  5. 「〜しなくてよい」は、must を使ってどのように表しますか（don't を使った形）。
  6. 「窓を開けてもいいですか。」と許可を求める文を英語にしなさい。
  7. 助動詞 should は、どのような意味を表しますか。
  8. I think that he is kind. の that の働きを答えなさい。
  9. When I got home, I was tired. の When I got home の意味を答えなさい。
  10. 助動詞 mustn't は、どのような意味を表しますか。
答えと解説を見る

答え

1) 〜だから（理由）　2) 〜とき　3) もし〜なら　4) You must do your homework.　5) don't have to　6) May I open the window?　7) 〜すべきだ　8) 〜ということ（2つの文をつなぐ）　9) 私が家に帰ったとき　10) 〜してはいけない

解説

because は理由を表し、「〜だから」と訳します。 when は時を表し、「〜とき」と訳します。 if は条件を表し、「もし〜なら」と訳します。 「〜しなければならない」は must を使います。You must do your homework. です。 must の否定には注意が必要です。「しなくてよい」は don't have to で表します。 許可を求めるときは May I 〜? が丁寧な言い方です。 should は「〜すべきだ」という助言や義務を表します。 that は「〜ということ」という意味で、前の文と後ろの文をつなぎます。 When I got home は「私が家に帰ったとき」という意味です。 mustn't は強い禁止で「〜してはいけない」という意味です。「しなくてよい」とは違います。

中2英語｜接続詞・助動詞 ドリル（2）

接続詞と助動詞（2）。空所補充が中心で、文法問題も入ります。全10問。

  1. 次の文の（ ）に適切な接続詞を入れなさい。I was tired, ( ) I went to bed early.（だから）
  2. 次の文の（ ）に適切な接続詞を入れなさい。( ) it rains tomorrow, we will stay home.（もし）
  3. 次の文の（ ）に適切な接続詞を入れなさい。I think ( ) he is kind.（〜ということ）
  4. 次の文の（ ）に適切な接続詞を入れなさい。( ) I got home, I took a shower.（〜したとき）
  5. 次の文の（ ）に適切な接続詞を入れなさい。He was sick, ( ) he went to school.（しかし）
  6. 次の文の（ ）に適切な接続詞を入れなさい。I stayed home ( ) I was sick.（なぜなら）
  7. 次の文を日本語にしなさい。When I was young, I lived in Osaka.
  8. 次の文の（ ）に適切な接続詞を入れなさい。Please call me ( ) you arrive.（着いたら）
  9. 次の2文を that を使って1文にしなさい。I know. He is a good player.
  10. 次の文の（ ）に適切な接続詞を入れなさい。I will help you ( ) you need help.（もし）
答えと解説を見る

答え

1) so　2) If　3) that　4) When　5) but　6) because　7) 私が子どものころ、大阪に住んでいました。　8) when　9) I know that he is a good player.　10) if

解説

理由と結果をつなぐ「だから」は so です。 「もし〜なら」は If を使います。 I think that ... で「〜だと思う」という意味になります。 「〜したとき」は When を使います。 反対の内容をつなぐ「しかし」は but です。 理由を表す「なぜなら」は because です。 When は「〜のとき」という意味で、時間を表します。 「〜したら（とき）」は when でつなげます。未来のことでも、when の後ろは現在形 arrive を使う点がポイントです。 I know that ... の形にします。that は省略されることもあります。 条件を表す if を使います。

中2英語｜接続詞・助動詞 ドリル（3）

接続詞と助動詞（3）。空所補充が中心で、文法問題も入ります。全10問。

  1. 次の文の（ ）に適切な語句を入れなさい。You ( ) stop here.（止まらなければならない）
  2. 次の文を日本語にしなさい。You must not run here.
  3. 次の文の（ ）に適切な語句を入れなさい。I ( ) get up early tomorrow.（起きなければならない）
  4. 次の文の（ ）に適切な形を入れなさい。He ( ) to study hard.（彼は一生懸命勉強しなければなりません）
  5. 次の文を「〜する必要はない」という意味に書きかえなさい。You must do it now.（今しなくてもよい、という文に）
  6. 次の文の（ ）に適切な語を入れなさい。( ) I use your pen?（使ってもいいですか）
  7. 次の文の（ ）に適切な語を入れなさい。You ( ) eat vegetables.（食べたほうがよい、という助言）
  8. 次の文を日本語にしなさい。You should see a doctor.
  9. 次の文の（ ）に適切な語を入れなさい。( ) you like some tea?（いかがですか）
  10. 次の文の誤りを直しなさい。You must to go now.
答えと解説を見る

答え

1) must　2) ここで走ってはいけません。　3) have to　4) has　5) You don't have to do it now.　6) May　7) should　8) あなたは医者に診てもらったほうがよいです。　9) Would　10) You must go now.

解説

「〜しなければならない」は must です。後ろは動詞の原形です。 must not は強い禁止「〜してはいけない」です。 have to も「〜しなければならない」という意味です。主語 I なので have to です。 主語が三人称単数の He のときは has to になります。 「〜する必要はない」は don't have to です。must not（禁止）と意味が違うので注意します。 許可を求める丁寧な言い方は May I ...? です。 助言「〜したほうがよい」は should です。 should は助言を表します。 勧める言い方は Would you like ...? です。 must の後ろは動詞の原形で、to はいりません。

中2英語｜接続詞・助動詞 ドリル（4）

接続詞と助動詞（4）。文法問題が中心で、空所補充・否定文への書き換えも入ります。全10問。

  1. 次の文の（ ）に当てはまる語を書きなさい。I think ( ) he is kind.
  2. 「私は忙しいので、行けません。」を英語にしなさい。because を使いなさい。
  3. 次の文の（ ）に当てはまる語を書きなさい。( ) it rains tomorrow, we will stay home.
  4. 「あなたは宿題をしなければなりません。」を英語にしなさい。must を使いなさい。
  5. 次の文を否定文にしなさい。You must run here.
  6. 「彼は病気かもしれない。」を英語にしなさい。may を使いなさい。
  7. 次の文の（ ）に当てはまる語を書きなさい。When I ( ) home, it was raining.
  8. 「窓を開けてもいいですか。」を英語にしなさい。May を使いなさい。
  9. 次の文の（ ）に当てはまる語を書きなさい。You ( ) to study hard. 義務を表す have を使いなさい。
  10. 次の文の誤りを直しなさい。You must to go now.
答えと解説を見る

答え

1) that　2) I can't go because I am busy.　3) If　4) You must do your homework.　5) You must not run here.　6) He may be sick.　7) got（came / arrived でも可）　8) May I open the window?　9) have　10) You must go now.

解説

I think that 〜 で「私は〜だと思う」です。that は省略されることもあります。 because は理由を表す接続詞です。「忙しいので」の順序に注意しましょう。 If は「もし〜なら」という条件を表します。未来のことでも、if の中では現在形 rains を使います。 must + 動詞の原形 で「〜しなければならない」です。強い義務を表します。 must not は「〜してはいけない」という禁止の意味です。「する必要がない」とは違うので注意しましょう。 may は「〜かもしれない」という推量を表します。be は原形です。 when の文では、過去の出来事同士をつなぎます。「家に着いたとき」という過去の文です。 May I 〜? は「〜してもいいですか」という丁寧な許可の求め方です。 have to + 動詞の原形 で「〜しなければならない」です。must とほぼ同じ意味です。 must の後ろは動詞の原形です。to は不要です。

中2英語｜接続詞と助動詞 単元確認テスト

接続詞と助動詞の単元確認テスト（全10問・目安15分）。文法問題が中心で、空所補充・疑問文への書き換えも入ります。問題は（1）when・because、（2）接続詞、（3）助動詞 must / have to など、（4）総まとめと応用の内容を混ぜて出しています。

  1. 「私は彼が来ると思います。」を英語にしなさい。that を使いなさい。
  2. 次の文の（ ）に当てはまる語を書きなさい。( ) I was a child, I lived in Osaka.
  3. 「あなたはこの薬を飲む必要はありません。」を英語にしなさい。don't have to を使いなさい。
  4. 次の文の（ ）に当てはまる語を書きなさい。She ( ) be at home now. 確信に近い推量の must を使いなさい。
  5. 「もし晴れたら、私たちは公園に行きます。」を英語にしなさい。If を使いなさい。
  6. 次の文を疑問文にしなさい。You have to leave now.
  7. 次の文の（ ）に当てはまる語を書きなさい。He was tired ( ) he went to bed early.
  8. 「彼女は医者になるでしょう。」ではなく「彼女は医者かもしれない。」を英語にしなさい。may を使いなさい。
  9. 次の文の（ ）に当てはまる語を書きなさい。You must not ( ) late for school.
  10. 次の文の誤りを直しなさい。Because he was sick, so he stayed home.
答えと解説を見る

答え

1) I think that he will come.　2) When　3) You don't have to take this medicine.　4) must　5) If it is sunny, we will go to the park.　6) Do you have to leave now?　7) so　8) She may be a doctor.　9) be　10) Because he was sick, he stayed home.（または He stayed home because he was sick.）

解説

think that 〜 の形です。未来のことは will を使って表します。 When は「〜のとき」という意味で、時間を表す文をつなぎます。 don't have to は「〜する必要はない」です。must not（禁止）と区別しましょう。 must には「〜に違いない」という強い推量の意味もあります。be は原形です。 if の文の中は現在形 is sunny、主の文は will を使います。 have to の疑問文は Do を使います。has to の場合は Does です。 so は「だから」という結果を表す接続詞です。前が原因、後ろが結果です。 may be で「〜かもしれない」です。断定を避ける表現です。 must not の後ろも原形 be です。「遅れてはいけない」は be late です。 英語では because と so を同じ文で重ねて使いません。どちらか1つにします。
