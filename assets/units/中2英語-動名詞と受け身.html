中2英語｜動名詞・受け身 ドリル（1）

動名詞（〜ing）の使い方と、受け身（be動詞＋過去分詞）の基礎を確認します。文法問題が中心です。

  1. 動名詞は、動詞をどのような形にしたものですか。
  2. 「私は本を読むことが好きです。」を英語にしなさい。
  3. enjoy の後ろには、動詞のどのような形が来ますか。
  4. 受け身の文は、be動詞と何を使って作りますか。
  5. 「この本は多くの人に読まれています。」を英語にしなさい。
  6. write の過去分詞形を答えなさい。
  7. 「英語はアメリカで話されています。」を英語にしなさい。
  8. 受け身の文で「〜によって」は、どの言葉で表しますか。
  9. 「私は宿題を終えました。」を finish を使って英語にしなさい。
  10. speak の過去分詞形を答えなさい。
答えと解説を見る

答え

1) ing形　2) I like reading books.　3) 動名詞（ing形）　4) 過去分詞　5) This book is read by many people.　6) written　7) English is spoken in America.　8) by　9) I finished doing my homework.　10) spoken

解説

動詞に ing をつけた形が動名詞で、「〜すること」という名詞の働きをします。 like の後ろに動名詞が来ます。I like reading books. です。 enjoy は後ろに動名詞しか置けません。不定詞は置けないので注意しましょう。 受け身は be動詞＋過去分詞 で作ります。 read の過去分詞は read（読み方はレッド）です。This book is read by many people. となります。 write の変化は write−wrote−written です。過去分詞は written です。 speak の過去分詞 spoken を使います。English is spoken in America. です。 動作をする人は by の後ろに書きます。 finish の後ろも動名詞です。I finished doing my homework. となります。 speak の変化は speak−spoke−spoken です。過去分詞は spoken です。

中2英語｜動名詞・受け身 ドリル（2）

動名詞と受け身（2）。空所補充が中心で、文法問題も入ります。全10問。

  1. 次の文の（ ）に適切な形を入れなさい。I enjoy ( play ) soccer.
  2. 次の文の（ ）に適切な形を入れなさい。( Read ) books is my hobby.
  3. 次の文を日本語にしなさい。She is good at singing.
  4. 次の文の（ ）に適切な形を入れなさい。Thank you for ( help ) me.
  5. 次の文の（ ）に適切な形を入れなさい。He finished ( do ) his homework.
  6. 「泳ぐことは楽しいです」を英語にしなさい。
  7. 次の文の（ ）に適切な形を入れなさい。I am interested in ( learn ) English.
  8. 次の文を日本語にしなさい。Watching movies is fun for me.
  9. 次の文の（ ）に適切な形を入れなさい。She stopped ( cry ).（泣きやんだ）
  10. 次の文の（ ）に適切な形を入れなさい。Before ( go ) to bed, I brush my teeth.
答えと解説を見る

答え

1) playing　2) Reading　3) 彼女は歌うことが得意です。　4) helping　5) doing　6) Swimming is fun.　7) learning　8) 映画を見ることは私にとって楽しいです。　9) crying　10) going

解説

enjoy の後ろには動名詞（ing形）が来ます。play → playing です。 文の主語になる場合は動名詞を使います。Reading books で「本を読むこと」です。 be good at ＋動名詞で「〜することが得意だ」という意味です。 前置詞 for の後ろは動名詞です。help → helping です。 finish の後ろには動名詞が来ます。do → doing です。 主語には動名詞 Swimming を使います。 前置詞 in の後ろは動名詞 learning です。 Watching movies が主語「映画を見ること」です。 stop ＋動名詞で「〜することをやめる」という意味です。 前置詞 Before の後ろは動名詞 going です。

中2英語｜動名詞・受け身 ドリル（3）

動名詞と受け身（3）。空所補充が中心で、文法問題も入ります。全10問。

  1. 次の文の（ ）に適切な形を入れなさい。This book ( ) written by him.
  2. 次の文を受け身の文にしなさい。He wrote this letter.
  3. 次の文の（ ）に適切な形を入れなさい。English ( ) spoken in many countries.
  4. 次の文を日本語にしなさい。This bridge was built in 1990.
  5. 次の文を受け身の文にしなさい。Many people love this song.
  6. 次の文の（ ）に適切な形を入れなさい。The window was ( break ) by the ball.
  7. 次の文の（ ）に適切な形を入れなさい。These cars ( ) made in Japan.
  8. 次の文を日本語にしなさい。I was surprised at the news.
  9. 次の文を受け身の文にしなさい。She teaches English.
  10. 次の文の（ ）に適切な形を入れなさい。The room ( ) cleaned every day.
答えと解説を見る

答え

1) was　2) This letter was written by him.　3) is　4) この橋は1990年に建てられました。　5) This song is loved by many people.　6) broken　7) are　8) 私はその知らせに驚きました。　9) English is taught by her.　10) is

解説

受け身は「be動詞＋過去分詞」です。過去のことなので was written になります。 目的語を主語にし、「be動詞＋過去分詞＋by 〜」の形にします。 現在のことなので is spoken です。speak の過去分詞は spoken です。 was built は build の受け身の過去形です。 目的語 this song を主語にし、is loved by ... の形にします。 break の過去分詞は broken です。 複数形の主語なので are made です。 be surprised at ... は「〜に驚く」という決まった表現です。 teach の過去分詞は taught です。現在の文なので is を使います。 「毎日掃除される」という現在の習慣なので is cleaned です。

中2英語｜動名詞・受け身 ドリル（4）

動名詞と受け身（4）。文法問題が中心で、空所補充も入ります。全10問。

  1. 「私は読書が好きです。」を英語にしなさい。動名詞を使いなさい。
  2. 次の文の（ ）に当てはまる形を書きなさい。 ( Swim ) is good for health. 動名詞にしなさい。
  3. 「この本は多くの人に読まれています。」を英語にしなさい。受け身の文にしなさい。
  4. 次の文を受け身に書きかえなさい。He wrote this letter.
  5. 次の文の（ ）に当てはまる形を書きなさい。The room is ( clean ) by her every day. 過去分詞にしなさい。
  6. 「彼はサッカーをすることを楽しみました。」を英語にしなさい。enjoy と動名詞を使いなさい。
  7. 次の文を受け身に書きかえなさい。They speak English in Australia.
  8. 次の文の（ ）に当てはまる形を書きなさい。I finished ( do ) my homework. 動名詞にしなさい。
  9. 「この橋は1960年に建てられました。」を英語にしなさい。建てるは build を使いなさい。
  10. 次の文の誤りを直しなさい。He is know by everyone.
答えと解説を見る

答え

1) I like reading books.　2) Swimming　3) This book is read by many people.　4) This letter was written by him.　5) cleaned　6) He enjoyed playing soccer.　7) English is spoken in Australia.　8) doing　9) This bridge was built in 1960.　10) He is known by everyone.

解説

like の後ろに動名詞 reading を置くことができます。「〜すること」という意味です。 文の主語になる場合は動名詞を使います。Swimming が主語です。 受け身は「be動詞 + 過去分詞」です。read の過去分詞は read です。 目的語を主語にし、過去の文なので was + 過去分詞 written を使います。 受け身では過去分詞を使います。clean の過去分詞は cleaned です。 enjoy の後ろは動名詞です。to play とは言いません。 一般的な事実なので現在形の受け身 is spoken を使います。by them は省略できます。 finish の後ろは動名詞です。do は doing になります。 build の過去分詞は built です。過去のことなので was を使います。 受け身では過去分詞 known が必要です。know の過去分詞は known です。

中2英語｜動名詞と受け身 単元確認テスト

動名詞と受け身の単元確認テスト（全10問・目安15分）。文法問題が中心で、空所補充も入ります。問題は（1）動名詞（〜ing）の使い方と、（2）動名詞、（3）受け身（受動態）、（4）総まとめと応用の内容を混ぜて出しています。

  1. 「歌を歌うことは楽しいです。」を英語にしなさい。動名詞を主語にしなさい。
  2. 次の文を受け身に書きかえなさい。She cleans the room.
  3. 次の文の（ ）に当てはまる形を書きなさい。This song is ( sing ) by many people. 過去分詞にしなさい。
  4. 「彼は走るのをやめました。」を英語にしなさい。stop と動名詞を使いなさい。
  5. 次の文を受け身に書きかえなさい。My father made this cake.
  6. 次の文の（ ）に当てはまる語を書きなさい。Thank you for ( ) me.
  7. 「日本では日本語が話されています。」を英語にしなさい。受け身を使いなさい。
  8. 次の文の（ ）に当てはまる形を書きなさい。The window was ( break ) yesterday. 過去分詞にしなさい。
  9. 「私はその映画を見たことを覚えています。」を英語にしなさい。remember と動名詞を使いなさい。
  10. 次の文の誤りを直しなさい。This picture was took last year.
答えと解説を見る

答え

1) Singing songs is fun.　2) The room is cleaned by her.　3) sung　4) He stopped running.　5) This cake was made by my father.　6) helping　7) Japanese is spoken in Japan.　8) broken　9) I remember watching the movie.　10) This picture was taken last year.

解説

動名詞 Singing songs が主語です。動名詞が主語のとき、動詞は単数扱いで is を使います。 現在の文の受け身は is + 過去分詞 です。by her をつけます。 sing の過去分詞は sung です。過去形 sang と区別しましょう。 stop の後ろに動名詞を置くと「〜するのをやめる」です。run は running になります。 make の過去分詞は made です。過去の文なので was を使います。 前置詞 for の後ろは動名詞 helping です。前置詞の後ろには名詞や動名詞が来ます。 話す言語が主語です。speak の過去分詞 spoken を使います。 break の過去分詞は broken です。 remember + 動名詞 は「〜したことを覚えている」です。 take の過去分詞は taken です。過去形 took と混同しないようにしましょう。
