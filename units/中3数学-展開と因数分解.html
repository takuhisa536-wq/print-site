中3数学｜展開と因数分解（1） 練習プリント

乗法公式を使った展開と、因数分解の手順を練習します。足し算が中心です。

  1. (x + 3)(x + 5) を展開しなさい。
  2. (x - 4)² を展開しなさい。（²は2乗のこと）
  3. (x + 7)(x - 7) を展開しなさい。
  4. x² + 6x + 9 を因数分解しなさい。
  5. x² - 5x + 6 を因数分解しなさい。
  6. 3x² + 6x を因数分解しなさい。
  7. (2x + 1)² を展開しなさい。
  8. x² - 16 を因数分解しなさい。
  9. (x + 2)(x - 3) を展開しなさい。
  10. x² + 2x - 8 を因数分解しなさい。
  11. (x + 4)(x + 6) を展開しなさい。
  12. (x - 5)² を展開しなさい。（²は2乗のこと）
  13. x² + 7x + 12 を因数分解しなさい。
  14. x² - 9 を因数分解しなさい。
  15. 2x² - 8x を因数分解しなさい。
答えと解説を見る

答え

1) x²+8x+15　2) x²-8x+16　3) x²-49　4) (x+3)²　5) (x-2)(x-3)　6) 3x(x+2)　7) 4x²+4x+1　8) (x+4)(x-4)　9) x²-x-6　10) (x+4)(x-2)　11) x²+10x+24　12) x²-10x+25　13) (x+3)(x+4)　14) (x+3)(x-3)　15) 2x(x-4)

解説

公式 (x+a)(x+b)=x²+(a+b)x+ab を使います。3+5=8、3×5=15 なので x²+8x+15 です。 公式 (x-a)²=x²-2ax+a² を使います。2×4=8、4²=16 なので x²-8x+16 です。真ん中の項の符号はマイナスです。 公式 (x+a)(x-a)=x²-a² を使います。7²=49 なので x²-49 です。真ん中の項が消えるのがこの公式の特徴です。 9=3² で、真ん中の 6x は 2×3×x と見られます。(x+3)² の形になる因数分解です。 かけて+6、足して-5になる2数は -2 と -3 です。よって (x-2)(x-3) です。因数分解は「かけて定数項、足して真ん中の係数」の組探しです。 共通因数は 3x です。3x でくくると 3x(x+2) となります。因数分解は、まず共通因数でくくれないかを最初に確認します。 (2x+1)²=(2x)²+2×(2x)×1+1²=4x²+4x+1 です。(2x)² が 4x² になることに注意しましょう（2x² ではありません）。 16=4² なので、a²-b² の形です。(x+4)(x-4) と因数分解できます。 (x+2)(x-3) を公式で展開します。2+(-3)=-1、2×(-3)=-6 なので x²-x-6 です。符号に注意しましょう。 かけて-8、足して+2になる2数は +4 と -2 です。よって (x+4)(x-2) です。定数項がマイナスのとき、2数は異符号になります。 公式 (x+a)(x+b)=x²+(a+b)x+ab を使います。4+6=10、4×6=24 なので x²+10x+24 です。 公式 (x-a)²=x²-2ax+a² を使います。2×5=10、5²=25 なので x²-10x+25 です。 かけて+12、足して+7になる2数は +3 と +4 です。よって (x+3)(x+4) です。 9=3² なので、a²-b² の形です。(x+3)(x-3) と因数分解できます。 共通因数は 2x です。2x でくくると 2x(x-4) となります。まず共通因数でくくれないかを最初に確認しましょう。

  1. 次の式を展開しなさい。(x + 4)(x + 3)
  2. 次の式を展開しなさい。(x - 5)²
  3. 次の式を因数分解しなさい。x² + 6x + 8
  4. 次の式を因数分解しなさい。x² - 9
  5. 次の式を展開しなさい。(2x + 1)(x - 3)
  6. 次の式を因数分解しなさい。3x² + 6x
  7. 次の式を因数分解しなさい。x² - 8x + 16
  8. 次の式を展開しなさい。(a + b)(a - b)
  9. 次の計算を、公式を使って簡単にしなさい。102 × 98
  10. 次の式を因数分解しなさい。x² + 2x - 15
答えと解説を見る

答え

1) x² + 7x + 12　2) x² - 10x + 25　3) (x + 2)(x + 4)　4) (x + 3)(x - 3)　5) 2x² - 5x - 3　6) 3x(x + 2)　7) (x - 4)²　8) a² - b²　9) 9996　10) (x + 5)(x - 3)

解説

(x+a)(x+b) = x²+(a+b)x+ab です。4+3=7、4×3=12 です。 (x-a)² = x²-2ax+a² です。2×5=10、5²=25 です。 足して6、かけて8になる2数は2と4です。 x²-a² = (x+a)(x-a) の公式を使います。9は3²です。 順にかけ算します。2x×x=2x²、2x×(-3)+1×x = -6x+x = -5x、1×(-3) = -3 です。 共通因数3xをくくり出します。これが因数分解の第一歩です。 かけて16、足して-8になる数は-4と-4です。(x-4)² となります。 (a+b)(a-b) = a²-b² です。和と差の積は2乗の差になります。 102×98 = (100+2)(100-2) = 10000-4 = 9996 です。 足して2、かけて-15になる2数は5と-3です。

  1. 次の式を展開しなさい。(x + 7)(x - 2)
  2. 次の式を因数分解しなさい。x² + 9x + 20
  3. 次の式を展開しなさい。(x + 6)²
  4. 次の式を因数分解しなさい。x² - 25
  5. 次の式を因数分解しなさい。2x² - 8x
  6. 次の式を展開しなさい。(3x - 2)(3x + 2)
  7. 次の式を因数分解しなさい。x² - 12x + 36
  8. 次の式を展開しなさい。(x - 1)(x - 6)
  9. 次の計算を公式で簡単にしなさい。51²
  10. 次の式を因数分解しなさい。x² + x - 6
答えと解説を見る

答え

1) x² + 5x - 14　2) (x + 4)(x + 5)　3) x² + 12x + 36　4) (x + 5)(x - 5)　5) 2x(x - 4)　6) 9x² - 4　7) (x - 6)²　8) x² - 7x + 6　9) 2601　10) (x + 3)(x - 2)

解説

7+(-2)=5、7×(-2)=-14 です。 足して9、かけて20になる2数は4と5です。 (x+a)² = x²+2ax+a² です。 25は5²なので、2乗の差の公式が使えます。 共通因数2xをくくり出します。 和と差の積の公式で、(3x)²-2² = 9x²-4 です。 36は6²、12は2×6なので、(x-6)² の形が使えます。 (-1)+(-6) = -7、(-1)×(-6) = 6 です。 51² = (50+1)² = 2500+100+1 = 2601 です。 足して1、かけて-6になる2数は3と-2です。
