中2数学｜連立方程式（1） 練習プリント

加減法と代入法、文章題まで。解き方の手順を1問ずつ確認できます。足し算が中心で、文章題も入ります。

  1. x + y = 5、x - y = 1 を解きなさい。
  2. 2x + y = 7、x + y = 4 を解きなさい。
  3. y = x - 2、2x + y = 7 を解きなさい。
  4. 3x + 2y = 12、3x - y = 3 を解きなさい。
  5. x + y = 10、2x + 3y = 26 を解きなさい。
  6. りんご1個を x 円、みかん1個を y 円とします。りんご2個とみかん3個で550円、りんご1個とみかん1個で200円でした。連立方程式を作り、りんごとみかんの値段を求めなさい。
  7. 2つの数 x、y の合計は30で、x は y より10大きいです。x と y を求めなさい。
  8. 4x - y = 5、2x + y = 7 を解きなさい。
  9. x - y = 2、3x + 2y = 16 を解きなさい。
  10. 100円の品物 x 個と80円の品物 y 個を合わせて20個買うと、代金は1800円でした。x と y を求めなさい。
  11. x + y = 6、x - y = 2 を解きなさい。
  12. 2x + y = 8、x + y = 5 を解きなさい。
  13. y = 2x、x + y = 9 を解きなさい。
  14. 3x + y = 10、x + y = 4 を解きなさい。
  15. 2つの数 x、y の合計は20で、x は y より4大きいです。x と y を求めなさい。
答えと解説を見る

答え

1) x=3、y=2　2) x=3、y=1　3) x=3、y=1　4) x=2、y=3　5) x=4、y=6　6) りんご50円、みかん150円　7) x=20、y=10　8) x=2、y=3　9) x=4、y=2　10) x=10個、y=10個　11) x=4、y=2　12) x=3、y=2　13) x=3、y=6　14) x=3、y=1　15) x=12、y=8

解説

2つの式を上下に足すと y が消えて 2x=6 となり x=3。x+y=5 に代入して y=2 です。文字を1つ消すのが加減法です。 上の式から下の式を引くと y が消えて x=3。x+y=4 に代入して y=1 です。 y=x-2 をもう一方の式に代入します。2x+(x-2)=7 となり 3x=9、x=3。y=3-2=1 です。片方が「y=〜」の形のときは代入法が速いです。 2つの式を引き算すると x が消えて 3y=9、y=3。3x-y=3 に代入すると 3x=6、x=2 です。 x+y=10 を2倍すると 2x+2y=20。これを 2x+3y=26 から引くと y=6。x+6=10 なので x=4 です。係数をそろえてから消すのが加減法のコツです。 式は 2x+3y=550 と x+y=200 です。下の式を2倍すると 2x+2y=400。引くと y=150。x+150=200 なので x=50。りんご50円、みかん150円です。答えを問題文に当てはめて検算しましょう（50×2+150×3=550 で合います）。 式は x+y=30 と x=y+10 です。代入すると (y+10)+y=30 となり 2y=20、y=10、x=20 です。 2つの式を足すと y が消えて 6x=12、x=2。2x+y=7 に代入して y=3 です。 x-y=2 より x=y+2。これを 3x+2y=16 に代入すると 3(y+2)+2y=16、5y+6=16、5y=10、y=2、x=4 です。 式は x+y=20 と 100x+80y=1800 です。下の式を20で割ると 5x+4y=90。x=20-y を代入すると 5(20-y)+4y=90、100-y=90、y=10、x=10 です。 2つの式を足すと y が消えて 2x=8、x=4。x+y=6 に代入して y=2 です。 上の式から下の式を引くと y が消えて x=3。x+y=5 に代入して y=2 です。 y=2x を x+y=9 に代入すると x+2x=9、3x=9 で x=3。y=2×3=6 です。 上の式から下の式を引くと y が消えて 2x=6、x=3。x+y=4 に代入して y=1 です。 式は x+y=20 と x=y+4 です。代入すると (y+4)+y=20、2y=16 で y=8、x=12 です。

中2数学｜連立方程式（2） 練習プリント

連立方程式（2）。x＋y と x−y の組み合わせや、2x＋y と x＋y の組み合わせなど、加減法で解く計算だけを10問集めました。全10問。

  1. 連立方程式 x + y = 5、x - y = -1 を解きなさい。
  2. 連立方程式 x + y = 5、x - y = 3 を解きなさい。
  3. 連立方程式 x + y = 6、x - y = -4 を解きなさい。
  4. 連立方程式 x + y = 5、x - y = 1 を解きなさい。
  5. 連立方程式 x + y = 9、x - y = 1 を解きなさい。
  6. 連立方程式 2x + y = 5、x + y = 3 を解きなさい。
  7. 連立方程式 2x + y = 9、x + y = 6 を解きなさい。
  8. 連立方程式 2x + y = 6、x + y = 5 を解きなさい。
  9. 連立方程式 2x + y = 10、x + y = 6 を解きなさい。
  10. 連立方程式 2x + y = 11、x + y = 6 を解きなさい。
答えと解説を見る

答え

1) x = 2、y = 3　2) x = 4、y = 1　3) x = 1、y = 5　4) x = 3、y = 2　5) x = 5、y = 4　6) x = 2、y = 1　7) x = 3、y = 3　8) x = 1、y = 4　9) x = 4、y = 2　10) x = 5、y = 1

解説

2つの式を加えると 2x = 4 となり x=2。x+y=5 に代入すると y=3 です。 2つの式を加えると 2x = 8 となり x=4。x+y=5 に代入すると y=1 です。 2つの式を加えると 2x = 2 となり x=1。x+y=6 に代入すると y=5 です。 2つの式を加えると 2x = 6 となり x=3。x+y=5 に代入すると y=2 です。 2つの式を加えると 2x = 10 となり x=5。x+y=9 に代入すると y=4 です。 上の式から下の式を引くと x = 2 = 2。x+y=3 に代入すると y=1 です。 上の式から下の式を引くと x = 3 = 3。x+y=6 に代入すると y=3 です。 上の式から下の式を引くと x = 1 = 1。x+y=5 に代入すると y=4 です。 上の式から下の式を引くと x = 4 = 4。x+y=6 に代入すると y=2 です。 上の式から下の式を引くと x = 5 = 5。x+y=6 に代入すると y=1 です。

中2数学｜連立方程式（3） 練習プリント

連立方程式（3）。問1〜5はりんごとみかんの個数と代金の文章題、問6〜10は2つの数の和と差から大きい方の数を求める文章題です。全10問。

  1. 1個 100 円のりんごと、1個 70 円のみかんを合わせて 5 個買うと 440 円でした。りんごは何個ですか。ただし、りんごを x 個、みかんを y 個として連立方程式を立てて考えなさい。
  2. 1個 80 円のりんごと、1個 50 円のみかんを合わせて 6 個買うと 360 円でした。りんごは何個ですか。ただし、りんごを x 個、みかんを y 個として連立方程式を立てて考えなさい。
  3. 1個 120 円のりんごと、1個 90 円のみかんを合わせて 6 個買うと 690 円でした。りんごは何個ですか。ただし、りんごを x 個、みかんを y 個として連立方程式を立てて考えなさい。
  4. 1個 90 円のりんごと、1個 60 円のみかんを合わせて 4 個買うと 270 円でした。りんごは何個ですか。ただし、りんごを x 個、みかんを y 個として連立方程式を立てて考えなさい。
  5. 1個 110 円のりんごと、1個 80 円のみかんを合わせて 6 個買うと 600 円でした。りんごは何個ですか。ただし、りんごを x 個、みかんを y 個として連立方程式を立てて考えなさい。
  6. 2つの数の和が 10、差が 2 です。大きい方の数を求めなさい。
  7. 2つの数の和が 10、差が 6 です。大きい方の数を求めなさい。
  8. 2つの数の和が 10、差が 0 です。大きい方の数を求めなさい。
  9. 2つの数の和が 12、差が 6 です。大きい方の数を求めなさい。
  10. 2つの数の和が 13、差が 1 です。大きい方の数を求めなさい。
答えと解説を見る

答え

1) 3 個　2) 2 個　3) 5 個　4) 1 個　5) 4 個　6) 6　7) 8　8) 5　9) 9　10) 7

解説

x+y=5 と 100x+70y=440 を解くと x=3、y=2。りんごは 3 個です。 x+y=6 と 80x+50y=360 を解くと x=2、y=4。りんごは 2 個です。 x+y=6 と 120x+90y=690 を解くと x=5、y=1。りんごは 5 個です。 x+y=4 と 90x+60y=270 を解くと x=1、y=3。りんごは 1 個です。 x+y=6 と 110x+80y=600 を解くと x=4、y=2。りんごは 4 個です。 大きい方を x、小さい方を y とすると x+y=10、x-y=2。加えると 2x=12 となり x=6 です。 大きい方を x、小さい方を y とすると x+y=10、x-y=6。加えると 2x=16 となり x=8 です。 大きい方を x、小さい方を y とすると x+y=10、x-y=0。加えると 2x=10 となり x=5 です。 大きい方を x、小さい方を y とすると x+y=12、x-y=6。加えると 2x=18 となり x=9 です。 大きい方を x、小さい方を y とすると x+y=13、x-y=1。加えると 2x=14 となり x=7 です。

中2数学｜連立方程式（4） 練習プリント

連立方程式（4）。加減法の計算に、x＝y や y＝2x を代入して解く問題、りんごとみかんの値段、2つの数の和と差の文章題を混ぜた総まとめです。全10問。

  1. 連立方程式 x + y = 7、x - y = 3 を解きなさい。
  2. 連立方程式 2x + y = 9、x + y = 6 を解きなさい。
  3. 連立方程式 3x + 2y = 12、x = y を解きなさい。
  4. 連立方程式 y = 2x、x + y = 9 を解きなさい。
  5. 連立方程式 4x + 3y = 18、2x + 3y = 12 を解きなさい。
  6. りんご3個とみかん2個で460円、りんご1個とみかん2個で260円でした。りんご1個の値段を求めなさい。
  7. 連立方程式 5x - y = 9、x + y = 3 を解きなさい。
  8. 連立方程式 2x + 5y = 16、2x + y = 8 を解きなさい。
  9. 大小2つの数があり、和が15、差が3です。大きい方の数を求めなさい。
  10. 連立方程式 3x - 2y = 7、x + 2y = 5 を解きなさい。
答えと解説を見る

答え

1) x = 5, y = 2　2) x = 3, y = 3　3) x = 2.4（12/5）, y = 2.4（12/5）　4) x = 3, y = 6　5) x = 3, y = 2　6) 100円　7) x = 2, y = 1　8) x = 3, y = 2　9) 9　10) x = 3, y = 1

解説

2つの式を足すと 2x = 10 となり x = 5、代入して y = 2 です。 上の式から下の式を引くと x = 3、代入して y = 3 です。 x = y を代入すると 3x+2x = 12、5x = 12 となり x = 12/5 です。分数の答えでも正解です。 y = 2x を代入すると x+2x = 9、x = 3、y = 6 です。 2つの式を引くと 2x = 6 となり x = 3、代入して y = 2 です。 りんごを x 円、みかんを y 円として式を立て、2つの式を引くと 2x = 200 となり x = 100 円です。 2つの式を足すと 6x = 12 となり x = 2、代入して y = 1 です。 2つの式を引くと 4y = 8 となり y = 2、代入して x = 3 です。 大きい数を x、小さい数を y とすると x+y = 15、x-y = 3 です。解くと x = 9 です。 2つの式を足すと 4x = 12 となり x = 3、代入して y = 1 です。

中2数学｜連立方程式 単元確認テスト

連立方程式の単元確認テスト（全10問・目安15分）。方程式を解く計算が中心で、文章題・足し算も入ります。問題は（1）加減法と代入法、文章題まで、（2）加減法の練習、（3）連立方程式の文章題、（4）総まとめと応用の内容を混ぜて出しています。

  1. 連立方程式 x + y = 10、x - y = 2 を解きなさい。
  2. 連立方程式 2x + 3y = 13、x = 2 を解きなさい。
  3. 連立方程式 y = x + 1、2x + y = 7 を解きなさい。
  4. 連立方程式 3x + y = 11、3x - y = 1 を解きなさい。
  5. 鉛筆5本と消しゴム3個で340円、鉛筆5本と消しゴム1個で260円でした。消しゴム1個の値段を求めなさい。
  6. 連立方程式 x + 4y = 14、x + y = 5 を解きなさい。
  7. 連立方程式 4x - y = 7、2x + y = 5 を解きなさい。
  8. ある2けたの数で、十の位と一の位の和が9、入れ替えるともとの数より27大きくなります。もとの数を求めなさい。
  9. 連立方程式 6x + 2y = 14、3x + y = 7 について、解はどうなりますか。
  10. 連立方程式 2x - 3y = 1、4x + 3y = 11 を解きなさい。
答えと解説を見る

答え

1) x = 6, y = 4　2) x = 2, y = 3　3) x = 2, y = 3　4) x = 2, y = 5　5) 40円　6) x = 2, y = 3　7) x = 2, y = 1　8) 36　9) 解は無数にある（2つの式が実質同じ）　10) x = 2, y = 1

解説

足すと 2x = 12 で x = 6、y = 4 です。 x = 2 を代入すると 4+3y = 13、3y = 9 で y = 3 です。 代入すると 2x+x+1 = 7、3x = 6 で x = 2、y = 3 です。 足すと 6x = 12 で x = 2、代入して y = 5 です。 式を引くと、消しゴム2個で80円の差になるので、1個40円です。 引くと 3y = 9 で y = 3、x = 2 です。 足すと 6x = 12 で x = 2、y = 1 です。 十の位を x、一の位を y とすると x+y = 9、(10y+x)-(10x+y) = 27 です。解くと x = 3、y = 6 で、もとの数は36です。 下の式を2倍すると上の式とまったく同じになるため、解は無数にあります。 足すと 6x = 12 で x = 2、代入して 4-3y = 1 より y = 1 です。
